Welcome to the CheckMate Setup Wizard.

This application is an accessible desktop front-end for the DAISY eBraille
Checker, W3C EPUBCheck, Ace by DAISY, the W3C Nu HTML Checker, veraPDF, and
DAISY Pipeline (when installed). It lets you open an .ebrl, .epub, .pdf,
.html, .svg, or .css file, a DTBook XML or NIMAS/DAISY package, or an exploded
publication folder, and see a clear Passed / Passed with warnings / Failed
result. .ebrl files are checked with eBraille Checker; .epub files with
EPUBCheck and Ace; .pdf files with veraPDF (PDF/UA or PDF/A); .html files with
the Nu HTML Checker and axe; .svg and .css with Nu. DAISY 2.02, DAISY 3,
DTBook, and NIMAS use a local DAISY Pipeline 2 webservice when it is running.

On Windows you can right-click an .ebrl, .epub, .pdf, .html, .svg, or .css
file and choose "Validate with CheckMate", or use Open with → CheckMate. On
Windows 11 that command is on the classic menu (right-click → Show more
options, or Shift+F10).

What this installer includes:
  • CheckMate
  • Bundled Eclipse Temurin Java Runtime (JRE 17)
  • Bundled eBraille Checker
  • Bundled EPUBCheck
  • Bundled Ace by DAISY (with Node.js and Chromium)
  • Bundled veraPDF
  • PyMuPDF (for PDF first-page previews in HTML reports)

No separate Java, Node.js, or Ace installation is required. DAISY Pipeline is
optional and is not bundled.
