Welcome to the eBraille Checker GUI Setup Wizard.

This application is an accessible desktop front-end for the DAISY eBraille
Checker, W3C EPUBCheck, and veraPDF. It lets you open an .ebrl, .epub, or .pdf
publication (or an exploded eBraille/EPUB folder) and see a clear Passed /
Passed with warnings / Failed result. .ebrl files are checked with eBraille
Checker; .epub files with EPUBCheck; .pdf files with veraPDF (PDF/UA).
Exploded folders are detected automatically.

On Windows you can right-click an .ebrl, .epub, or .pdf file and choose
"Validate with eBraille Checker", or use Open with → eBraille Checker.

What this installer includes:
  • eBraille Checker GUI
  • Bundled Eclipse Temurin Java Runtime (JRE 17)
  • Bundled eBraille Checker
  • Bundled EPUBCheck
  • Bundled veraPDF
  • PyMuPDF (for PDF first-page previews in HTML reports)

No separate Java installation is required.
