CheckMate — install

1. Drag CheckMate.app onto the Applications folder (shortcut in this window).

2. Open Applications and launch CheckMate.

Upgrading
---------
If macOS says a newer version is already installed, remove the old copy first:
  • Open Applications, drag CheckMate.app to the Trash, then empty Trash.
  • Drag this disk image’s CheckMate.app onto Applications again.

The bundled Java runtime and checker are inside the app — no separate install step.
